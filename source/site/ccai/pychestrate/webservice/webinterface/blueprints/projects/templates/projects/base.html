Pages that extend this template render as a content fragment injected into the main slot by render_shell_document(content_html=...) -- see projects/routes.py::_wrap_projects_handler_in_shell. The shell owns the surrounding chrome (header, sidebar, layout, theme); this fragment contributes only the page-specific body, the per-project sub-navigation column, any extra CSS, and any extra JS. The legacy standalone chrome (own //, the navy-gradient app header, the fixed global sidebar, the logout form, and the Vue / bootstrap-vue script stack) is intentionally gone -- the site shell provides all of it. What remains of the old sidebar is the per-project sub-navigation, kept as an in-content left column: once a project is selected it gives the 15 project-scoped destinations a stable home without competing with the shell's global sidebar. Child templates still declare {% raw %}{% block title %}{% endraw %} blocks; they are intentionally never rendered here -- the shell document's comes from the wrapper's page-title table. Colors reference the --pyc-* design tokens (with light-palette fallbacks) from /static/styles/pyc-tokens.css, which the shell document links, so this section follows light / dark automatically.
